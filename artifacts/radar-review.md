## 這次改動

- 餐桌場景交代晚餐後將陪奶奶（家人也叫她阿嬤）出門洽公；後續場景延續同一晚、同一位同行者。
- 回聲可為文字或函式，並依先前選擇補上跨幕回憶，例如月台先問阿嬤、扶梯改搭電梯與文件袋一路拿穩。
- 結尾依實際選擇挑出二至四個短記憶，保留房間、聲音、提問三種結尾語氣，並收束至雨停後一起回家。
- 新增本機 Web Audio 提示音開關，預設關閉；偏好存於 `you-have-manners-audio-v1`，進度仍採原有 `v1` 格式與本機 `localStorage`。
- 新增零相依套件的 Node 冒煙檢查，涵蓋六幕、回聲、跨幕回憶、結尾記憶與進度序列化往返。

## 手動檢查

在專案根目錄啟動靜態伺服器：

```sh
python3 -m http.server 4173
```

開啟 `http://localhost:4173/` 後，建議依序確認：

1. 開場提到陪阿嬤度過同一個傍晚；桌邊稱她奶奶，也交代家人稱呼她阿嬤。
2. 保持提示音關閉時選擇與換幕，不應播放聲音；開啟後再操作，應聽見輕柔短音。重新載入後確認開關狀態保留，且可關閉。
3. 月台選「先問阿嬤想怎麼走」，到櫃台確認回聲提到月台；扶梯選「改搭旁邊電梯」，到圓桌確認回聲提到文件袋拿穩。
4. 完成六幕，確認結尾列出實際選擇的二至四個畫面，並以雨停、與阿嬤走回家收尾。
5. 重新載入故事中途，確認原有選擇仍可從本機進度恢復；「重新開始」仍可清除進度。
6. 執行 `node --check app.js`、`node --check story-data.js` 與 `node artifacts/smoke-story.mjs`。
