# 你有禮貌嗎？

一段從家裡餐桌走到公寓門口、公車站與街角小店的互動故事。每個事件都可以停下來想一想、選一條路，看見選擇帶來的回聲；沒有分數，也不判定誰比較有禮貌。

## 開啟方式

這是純 HTML、CSS、JavaScript 靜態網站，不需安裝相依套件。在專案根目錄執行：

```powershell
python -m http.server 4173
```

再開啟 `http://localhost:4173/`。全景插畫位於 `assets/story-panorama.png`。
