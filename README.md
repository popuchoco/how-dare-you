# 你有禮貌嗎？留一點空間

一段沿著黃昏街景展開的互動故事：在家裡、公共空間與日常對話裡，試著看見彼此的需要。沒有測驗分數；每個選擇都有一段回音，也可以重新選。

## 開啟方式

此專案是純 HTML、CSS、JavaScript，無需安裝相依套件。於此資料夾執行：

```powershell
python -m http.server 4173
```

再瀏覽 `http://localhost:4173/`。若使用其他靜態伺服器，請讓 `index.html`、`styles.css`、`app.js` 與 `assets/panorama.png` 保持相對路徑。

## 互動內容

- 可拖動的橫向城市全景與四個場景光點
- 家庭對話、搭車、朋友家、電話對話四段選擇式微故事
- 每個選擇都提供不同回音，可重新試試；不評分、不記錄個人資料
- 對禮儀慣例、社會習俗與公共空間設計的延伸思考
- 低年級生活課程共讀提示與原始資料連結
